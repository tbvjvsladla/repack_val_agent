# 리뷰 스킬 설치 수행계획

## 수행 계획과 완료 기준

1. 원본 명령·6개 agent·manifest·marketplace·LICENSE와 공식 Codex 이식 지침을 확인한다.
2. 두 독립 프로젝트 스킬에 전문 검토 참조·출처·의존성과 실행 제약을 포함한다. README보다 현 command/agent의 실행 계약을 우선한다.
3. quick_validate와 네이티브 app-server skills/list로 두 로컬 스킬을 검증한다.
4. 설치된 스킬의 전문 subagent 지침으로 작은 고장·정상 사례를 실제 검토하고 누락·오탐·읽기 범위를 평가한다. 현재 Codex 도구의 동시성 안에서 wave를 사용하고 완료를 기다린다.
5. 독립 Validator가 설치본·원본 대응·실행 근거를 직접 읽고 판단한다. 작업 문서를 위키에 입고하고 check한다.

도구가 없는 실행 경로는 실제 미검증으로 보존한다. gh는 현재 PATH에 없고 GitHub 인라인 MCP도 현재 도구 카탈로그에서 발견되지 않았다. 로컬/제공된 PR snapshot은 그 도구 없이 검토 가능하게 한다. 원본 toolkit README의 build-validator는 권장 연계이지 선언 의존성이 아니다. 별도 code-simplifier 플러그인을 추가하지 않는다.

## 실행 결과

두 개의 자체 완결 Codex 스킬과 toolkit의 6개 전문 참조를 설치했다. 원본 동작에서 이식이 필요한 지점·의존성·LICENSE 차이를 기록했다. 네이티브 발견과 실제 전문·독립 검토를 수행했고 별도 Validator의 직접 검토를 받았다. 위키 sync 계획·apply·check를 마치고 마감했다. gh/MCP 없이 로컬과 제공된 snapshot 검토를 지원하며 GitHub 인증·게시 기능은 별도 미검증이다.
