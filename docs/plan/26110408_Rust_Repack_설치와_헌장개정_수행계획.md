# Rust Repack 설치와 헌장개정 수행계획

## 승인과 구현 범위

사용자가 인터뷰 문서를 근거로 plan 생성, 스킬 및 헌장 개정을 모두 수행하도록 명시 지시했다. 직전 클린코드 재작성안을 구현 기준으로 채택하는 후속 실행 지시로 기록한다. 인터뷰를 다시 시작하거나 Seed 승인을 가정하지 않는다. 같은 task_id와 기존 합의를 이어받는다.

- `.agents/skills/rust-repack/`에 자체 완결 Rust 변환 스킬 설치. BeautifulRust의 행동 중심 포팅을 기반으로 새 지침을 작성하고 MIT 고지를 보존한다.
- rust-skills의 선택적 Rust 설계 관점을 자체 완결 자료로 정리한다. 원문 라이선스가 불명확한 파일은 복사하지 않는다. 광역 router/hooks는 설치하지 않는다.
- rust-analyzer-mcp는 실제 도구가 있을 때 쓰는 선택 보조 경로로 문서화한다. 전역/호스트 MCP 등록이나 toolchain 설치를 스킬이 자동 수행하지 않는다.
- 기존 두 리뷰 스킬에서 상대 스킬과 worker의 존재·역할·선택·호출 지침을 제거한다. 출처·기존 전문 절차·권한 제한은 보존한다.
- workflow 헌장에는 도메인 중립의 실효성·통합·시나리오·성능 평가, 도구 독립성과 외부 오케스트레이션 책임을 추가한다. docs 헌장에는 과업 plan/checklist에서 연계·실행 조건을 구체화하도록 명시한다.

Rust 명명·주석·Cargo 명령·고정 worker 경로·성능 수치는 헌장에 넣지 않는다. 실제 제품/worker 코드 이식·배포·기존 seed 변경·전역 설정·Git 커밋/푸시는 범위 밖이다.

## 세부 적용 결정

미결정 세부는 스킬의 과업 입력 계약으로 남긴다: source/대상 경로, 보존 계약, Rust/MSRV/edition/features, 의존성 허용 범위, shim 지정, 원본 실행 환경. 기존 저장소 규약을 따른다. 주석 언어는 과업 지정→대상 저장소 관례, 둘 다 없으면 확인한다. Rust 버전을 임의로 최신으로 고정하지 않는다. 테스트가 없으면 관측된 원본 동작의 특성화 테스트를 작성하고 기존 테스트가 없다는 사실을 기록한다. 판단에 필요한 원본/계약이 없으면 누락을 반환한다. 실제 지원 범위 밖의 의미를 임의 축소하지 않는다.

## 수행 순서

1. 공식 로컬 스킬 규격·원본 LICENSE·확정 합의 확인, 입력 상태 보존.
2. 스킬 본문, 내부 클린코드/의미 호환/도구·검사 참고자료 작성. 외부 스킬 이름·호출은 넣지 않는다.
3. 기존 스킬 결합 지침 제거, 두 헌장에 공통 운영 원칙 반영.
4. quick_validate·참고 링크·네이티브 skills/list로 설치 구조와 인식 확인.
5. 격리 temp 작업영역에서 실제 변환 시험: Python과 JavaScript 원본·테스트를 제공하고 설치 스킬만으로 Rust 변환. 기존 호출 출력·오류·순서·종료 코드와 자체검사 실행을 확인. 환경 부재·누락 입력·미지정 shim·비대상 요청도 확인.
6. 독립 Validator가 최종 파일·명령 근거·행동 시험 산출물을 직접 읽고 수용 기준과 대조한다. 필요하면 Builder에게 수정 반환, 영향받은 검사만 재실행.
7. 네 문서와 위키를 입고하고 최종 상태·한계를 보고.

검증용 Rust toolchain이 없으면 temp 내부에 공식 배포본을 설치할 수 있다. 사용자 전역 셸/설정은 바꾸지 않는다. 시험용 toolchain과 제품 운영 환경을 혼동하지 않는다. 선택적 MCP 부재는 cargo 기반 변환 경로를 막지 않지만 MCP 접속 성공으로 보고하지 않는다.

## 완료 기준

checklist AC01–AC08 충족과 독립 검토가 필요하다. 실제 변환 시험은 선택된 입력과 환경의 결과이며 모든 언어·성능 우위의 증명이 아니다. 환경 문제로 실행이 불가하면 실패·미실행을 보존하고 완료로 표시하지 않는다.

## 복구·재개

기존 변경을 보존하고 새 스킬과 이번 수정 파일만 되돌릴 수 있도록 diff로 경계를 관리한다. 무관한 파일을 일괄 restore하지 않는다. 원본 seed를 유지한다. 중단 시 devlog에 현재 파일·원시 로그·남은 기준·재개 명령을 기록한다.


## 이번 과업의 도구 연계와 검증 역할

메인 Builder는 rust-repack 본문·자료와 기존 리뷰 스킬 결합 안내 및 두 헌장을 수정한다. 별도 실행 에이전트는 설치된 rust-repack과 고정 원본 fixture를 입력받아 격리된 Python/JavaScript 변환 결과·검사 로그를 반환한다. 경계 시나리오 실행은 도구 부재·누락·비대상·미지정 연결의 실제 응답과 부분 결과를 반환한다. fixtures·검사 정답과 설치된 스킬은 실행 에이전트의 쓰기 범위 밖이다.

메인은 실제 원본과 Rust CLI 출력·stderr·종료 코드를 비교한다. 최종 검토에는 pr-review-toolkit의 code/comments/tests 관점을 적용하고, 각 전문 절차는 독립 읽기 맥락에서 수행한다. 형식/지침과 테스트 품질이 대상이며 별도 타입 모델 설계나 제품 오류처리 개편은 없다. 수정은 Builder에게 반환하고 근거가 바뀐 검사만 재실행한다. 최종 Validator는 checklist와 실행 근거를 직접 대조한다. 외부 게시·배포 없이 로컬 보고서로 종료한다.


## 수행 완료

설치·개정과 계획된 검증을 수행했다. 두 실제 변환, 네 경계 응답 시나리오, 세 전문 검토와 별도 최종 Validator를 완료했고 수정이 필요한 차단 finding은 없었다. 독립 평가가 유효한 실행 근거를 재사용했고 본 과업의 필수 기준을 추가·완화하지 않았다. 최종 문서 결과 반영 후 wiki sync/check로 입고를 마감한다.
