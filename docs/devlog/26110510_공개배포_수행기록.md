# 공개배포 수행기록

## 조사와 결정

두 헌장과 wiki-desk를 읽고 공개 준비를 별도 과업으로 시작했다. 기존 Git은 master·remote 미설정이며 `.codex/config.toml`만 미추적이었다. 루트 seed/temp/tests와 Ouroboros 실행 데이터는 이미 제외되어 있다. 실제 worker config는 추적 중이고 docs에는 개인 절대 경로와 실제 native session UUID가 있다. 공개본을 별도로 만들어 기존 이력과 실행 중인 다른 세션을 보존한다.

## 현재 상태

사용자 MIT 지정과 `seed/` 추적 제외 정정을 반영했다. 공개본 생성기·안내 문서·검사는 아직 구현 전이다. GitHub 대상의 읽기 전용 `git ls-remote`는 종료 0·ref 없음으로 관측됐다. 로컬 gh 실행파일·토큰 환경변수·gh 인증 파일·Git credentials 파일은 확인 범위에서 없었다. 인증 성공이나 발행 성공을 주장하지 않는다.

위 문단은 착수 시점의 관측이다. 이후 실제 구현·인증·발행 결과는 다음과 같다.

## 변경과 첫 실패

README·PUBLICATION·MIT LICENSE·외부 출처 고지, 워커 `config.example.json`, `scripts/prepare_public.py`를 추가했다. `.gitignore`에 개인 Codex 설정·실제 워커 설정·자격증명과 파생 캐시를 추가했고 기존 `/seed/`·`/temp/`·`/tests/` 제외를 유지했다. 추적 중인 원본 워커 설정은 지우거나 index에서 제거하지 않았다. 공개본 생성기의 명시 제외로 실제 설정이 발행되지 않게 했다.

첫 생성은 기존 receipt 없이 wiki sync를 호출해 종료 1이었다. 위키의 정식 `init` 계획·적용 후 sync 계획·적용·check를 수행하도록 수정했다. 기존 위키 receipt를 조작하거나 원본 카드를 복사하지 않는다.

별도 Validator가 첫 후보의 `agents/openai.yaml`에 남은 실제 대상명 1건을 확인했다. Markdown 이외에도 환경값 익명화·잔류 검사를 적용하고 YAML 회귀 검사를 추가했다. 새 후보 v2를 직접 재검증받아 PASS했다. 최초 FAIL과 재검증은 `temp/public-release-validation/independent-review.json`에 함께 보존했다.
