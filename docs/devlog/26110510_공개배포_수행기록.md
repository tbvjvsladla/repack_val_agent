# 공개배포 수행기록

## 조사와 결정

두 헌장과 wiki-desk를 읽고 공개 준비를 별도 과업으로 시작했다. 기존 Git은 master·remote 미설정이며 `.codex/config.toml`만 미추적이었다. 루트 seed/temp/tests와 Ouroboros 실행 데이터는 이미 제외되어 있다. 실제 worker config는 추적 중이고 docs에는 개인 절대 경로와 실제 native session UUID가 있다. 공개본을 별도로 만들어 기존 이력과 실행 중인 다른 세션을 보존한다.

## 현재 상태

사용자 MIT 지정과 `seed/` 추적 제외 정정을 반영했다. 공개본 생성기·안내 문서·검사는 아직 구현 전이다. GitHub 대상의 읽기 전용 `git ls-remote`는 종료 0·ref 없음으로 관측됐다. 로컬 gh 실행파일·토큰 환경변수·gh 인증 파일·Git credentials 파일은 확인 범위에서 없었다. 인증 성공이나 발행 성공을 주장하지 않는다.
