# 공개배포 검증목록

| 항목 | 기대 조건 | 상태 | 관측·근거 |
|---|---|---|---|
| 공개 구성 | 헌장·스킬·정리된 docs·위키·MIT·사용 안내 포함 | NOT_RUN | 구현 전 |
| 비공개 제외 | seed/temp/루트 tests/실제 config/인증/실행 데이터/원본 Git 제외 | NOT_RUN | 생성 후 검사 |
| 문서 익명화 | 개인 경로·대상명·실제 세션값 제거, task_id·판정·수치 보존 | NOT_RUN | 생성 후 대조 |
| 생성기 실패 경계 | 기존 출력·허용 밖 경로·symlink·의심 자격증명 거부 | NOT_RUN | 임시 fixture로 확인 |
| 원본 보존 | 기존 코드·설정·이력·index·remote 변경 없음 | NOT_RUN | 전후 대조 |
| 위키 | 원본과 공개본 각각 sync 계획 확인·적용·check 통과 | NOT_RUN | 문서 갱신 후 실행 |
| 스킬 | 공개본 설치 자산의 적용 가능한 자체검사 통과 | NOT_RUN | 실행 예정 |
| 원격 발행 | 별도 공개 저장소에서 push 후 원격 ref 확인 | NOT_RUN | 인증 가능 여부 미확정 |
| 외부 프로젝트 재실행 | 이번 과업 범위 밖 | NOT_APPLICABLE | 다른 세션에서 수행 중 |
| 성능·Rust 검증 | 공개 구성 변경으로 외부 구현·성능을 판정하지 않음 | NOT_APPLICABLE | 기존 문서 판정 보존 |

검증 준비와 실제 발행을 구분한다. 자기 점검을 독립 검토로 표시하지 않는다. 원시 로그는 공개하지 않으므로 기존 성과의 독립 재현을 보증하지 않는다.
