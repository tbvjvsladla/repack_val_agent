# 공개배포 요구합의

사용자는 외부 프로젝트의 Rust 리팩토링과 Harness² 개선을 지휘하는 val_agent의 절차를 공개하려 한다. 다른 사람이 참고할 수 있도록 `docs/`의 작업 이력과 작업수행규칙을 포함하고, 공개하면 안 되는 파일은 Git에서 제외하도록 요청했다. 대상 저장소는 사용자가 제시한 GitHub의 `repack_val_agent`다.

사용자는 기본 라이선스를 **MIT**로 명시했다. 이어서 루트 `seed/`는 Git 추적 제외임을 재확인했다. 기존 외부 스킬의 라이선스·저작권·출처는 보존한다.

공개 범위는 프로젝트 지침, 두 헌장, 설치 스킬과 내부 회귀 테스트, 익명화한 과업 문서, 재생성한 포인터 위키, 사용·공개 절차다. 비공개 범위는 외부 대상 프로젝트 코드, `seed/`, `temp/`, 루트 `tests/`, 실행 데이터·캐시·인증정보·개인 설정·실제 워커 설정·Git 원본 이력이다. 문서의 개인 절대 경로·대상 프로젝트명·실제 세션 식별자는 공개본에서 바꾸며 원본 문서는 보존한다.

다른 대화 세션에서 진행 중인 리팩토링을 재시작하거나 외부 프로젝트·실행 세션·전역 설정을 수정하지 않는다. 공개용 새 복사본을 만들고, 원본 저장소의 브랜치·index·remote·기존 커밋 이력은 변경하지 않는다. 외부 발행을 실행할 수 없으면 준비된 공개본과 남은 조건을 구분해 보고한다.

2026-11-05T11:01:30+09:00: 독립 검증을 통과한 공개 후보를 사용자가 제시한 `repack_val_agent`의 새 `main` 이력으로 발행했다. 사용자 승인 범위는 이 공개 요청과 MIT 지정이며, 검사 결과를 별도의 사용자 수용 선언으로 바꾸지 않는다.
