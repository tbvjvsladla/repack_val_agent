# 리뷰 스킬 설치 요구합의

사용자는 seed/rust_proj/claude-plugins-official의 pr-review-toolkit·code-review를 val_agent 프로젝트 로컬 스킬로 설치하고, 내부·외부 연계를 조사해 Claude 원본의 검토 능력을 최대한 보존하도록 요청했다. 현재 val_agent의 실행 주체는 Codex다.

두 스킬을 `.agents/skills/`에 설치한다. 6개 전문 검토·4개 독립 PR 검토·후보 재검증을 보존하고 Codex 도구/지침에 맞춰 변환한다. 원본 seed·기존 스킬·전역 설정·worker는 수정하지 않는다. 성능 동등성은 비교 실험 없이 보증하지 않는다. 리뷰는 읽기 중심이고 수정·GitHub 게시에는 해당 과업의 별도 명시 지시가 있어야 한다.
