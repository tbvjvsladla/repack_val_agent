# Rust 하네스 조사 요구합의

## 사용자 요청과 합의

사용자는 seed의 Python→Rust 하네스 분석·후보 조사 두 문서를 읽고, Rust 코드 변환에 사용할 공개 스킬·MCP·플러그인을 조사해 직접 다운로드·clone할 수 있는 자료를 새 `docs/request/` 폴더에 발행하도록 요청했다.

현재 운영 결정은 Codex 지휘, 기본 Claude Code 워커, 명시 요청 시 Codex CLI 워커다. 기존 보고서의 Hermes·경리나라 전용 설명을 현재 설치 계약으로 옮기지 않는다.

이번 범위는 원문 조사·원저장소 확인·우선순위 및 취득 명령 문서화와 위키 입고다. 사용자가 후속 다운로드를 할 수 있도록 작성하며 이번에는 seed clone, 도구 설치·활성화, 워커 실행 또는 코드 전환을 수행하지 않는다. 별도 인터뷰가 필요한 미결정은 없다.
