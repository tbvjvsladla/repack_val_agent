[제공 PDF](<../../seed/paper/HarnessTax_ How Much Does the Harness Matter for Coding Agents_ - Arena.pdf>)의 텍스트가 폰트 인코딩으로 손상되어 [Arena 발행자 원문](https://arena.ai/blog/coding-agents-harness-tax)을 직접 확인했다.

7모델×3harness를 두 benchmark에서 각각 30과업×3회 비교한다. 과업별 평균에 대한 bootstrap 95% 신뢰구간, 고정 API 단가, 시도별 100턴 상한을 명시한다. 같은 모델의 비슷한 성공률에도 비용 차이가 나며 초기 context·생성 토큰·cache·후속 호출을 함께 살펴야 한다.

**설계 의제라는 해석:** 성공률만으로 채택을 판정하지 않고 전체 비용·시간과 함께 비교할 필요가 있다. 이 연구의 반복수·턴수·비용 차이와 특정 harness 우위를 val_agent의 보편 합격선으로 가져오지 않는다.

### Agent Skills Can Be Harmful

[제공 PDF](<../../seed/paper/Agent Skills Can Be Harmful- An Empirical Study of Skill-Induced Failures in LLM Agents.pdf>), arXiv 2608.11888v1의 §III–V 및 §VII 관련 구간을 읽었다. 연구는 task/model/framework/verifier/repo/environment/input를 고정한 no-skill 또는 matched-skill 대조를 사용한다.

기능 실패는 적용 부적합, 요구 오구현·누락, 산출물 위치와 환경 불일치로, 효율 회귀는 context 비대화, 과잉 탐색·구축·검증과 의존성 수리로 나눈다. 분석 표본은 125 기능 실패와 182 효율 회귀다. 특히 주제상 적합한 스킬도 요구를 왜곡할 수 있고 선택 절차를 필수로 만들어 비용을 늘릴 수 있다는 관찰이다.

§III의 비용 회귀 탐지식은 양쪽 PASS일 때 `min(token_ratio,time_ratio)>1 AND max(token_ratio,time_ratio)>2`다. 이는 해당 연구의 큰 회귀를 고르는 기준이며 우리 수용선으로 확정하지 않았다. PASS/FAIL은 단일 실행 판정, reference는 pseudo-oracle이며, 저자도 분류의 주관성과 일반화 한계를 밝힌다. 해당 사례 수나 triage 일치율을 통계적 인과 증명·우리 프로젝트의 실패율로 해석하지 않는다.
