# Harness² 개선 루프

하네스의 반복 개선이 필요할 때 사용한다. 메인이 승인 범위 안에서 호출 여부를 정한다. 목표·허용 변경·필수 신뢰성·실험 예산은 입력으로 받고, 후보와 근거·선택 보류/선택·한정된 경험을 반환한다. 최종 수용과 실제 실행 권한은 호출자가 소유한다.

이 설치본은 Harness² **방법의 적용**이다. 원형 연구 엔진이나 benchmark adapter를 설치·호출하지 않는다. CLI는 JSON 근거와 상태를 관리한다. 후보의 작성·대조 해석·조합·회고는 에이전트가 수행하고, 실행·평가는 호출자가 연결한 외부 주체가 수행한다. [출처와 차이](references/provenance.md)를 참고한다.

## 실험 입력과 진행

CLI: `node <이 스킬 절대경로>/src/cli.mjs <command> <실험 디렉터리> <input.json>`. `status`는 input 없이 사용한다. 입력 형식·예시는 [실험 계약](references/protocol.md)에 있다. 필요한 부분만 읽는다.

- **고정:** 목표, task/experiment/evaluation/source ID, 변경 경로, 필수 검사와 실제 평가 명세 파일, case별 비교 조건, 기준선 산출물, 시도 예산을 호출자에게서 받는다. 새 실험의 `init`은 기존 실험을 덮어쓰지 않는다.
- **제안:** 관측한 병목과 바꿀 요소를 가설로 적고 `propose`로 부모·불변 후보 산출물·변경 경로를 기록한다. 근거 없는 개선 효과를 먼저 선언하지 않는다.
- **탐색:** `request`로 실행 요청을 먼저 등록한 뒤 외부 실행기에 전달한다. 실행 결과는 `observe`, 고정 기준의 외부 판정은 `evaluate`로 받는다. 이 도구가 모델·SSH·빌드·발행을 대신 실행하지 않는다.
- **대조·조합:** 시도 ID와 관측을 `contrast`에 연결한다. 여러 후보를 조합한 새 `propose`에는 모든 부모를 다룬 contrast를 연결한다. 조합 결과는 새로 실행·평가한다. 부모의 PASS를 물려주지 않는다.
- **선택:** 호출자의 `select`는 기준선과 후보의 모든 case에서 최신 시도의 필수 검사가 PASS인 경우에만 SELECTED를 반환한다. 부족하면 WITHHELD다. 기준선 유지도 가능하다. SELECTED는 실험 안의 자격 확인이며 최종 수용이 아니다.
- **회고:** 실행 원시 근거가 있는 시도를 `reflect`에 연결하고 cue·lesson·적용 범위·한계를 적는다. 실패에서도 배우되 관측보다 넓은 일반화를 하지 않는다. 경험의 후속 채택·배포에는 호출자 검토가 필요하다.

새 후보/조합에서 이 루프를 반복할 수 있다. 필수 신뢰성을 통과한 뒤 같은 비교 조건의 실제 연산시간·자원을 살핀다. 예산을 소진하면 결과와 보류 사유를 반환한다. 후보의 요구 누락·산출물 경로 변화·불필요한 탐색/검증·의존성 작업도 과업에 맞는 필수 검사나 관측값으로 포함한다.

## 근거와 재개

`request`부터 모든 시도를 분모에 남긴다. 실패·누락·미실행·판정 불가를 성공으로 바꾸지 않는다. 관측값이 없으면 null/NOT_RUN이며, 재시도·실패의 관측 시간과 비용도 합산하되 미측정 수를 함께 반환한다. 같은 계층 비용을 중복 입력하지 않는다. 대비되는 기능·측정 성립·서비스 성능 판정은 과업 계약에서 별개 검사로 둔다.

CLI의 `resume`에 원래 계약을 다시 제공한다. 계약·후보·이미 수집한 근거가 달라지면 재사용을 거부한다. 읽기 상태는 변경된 근거와 선택의 STALE 상태를 보여준다. 이는 로컬 실험 재개이며 미완료 원격 campaign 복구 기능은 제공하지 않는다. 외부 실행의 재접속·실제 모델/effort·campaign 상태·부수효과 중복 여부는 외부 실행기가 근거와 함께 반환해야 한다. 요청을 다시 실행하기 전에 상태를 확인한다.

역할 ID와 비교 조건은 호출자가 제공한 귀속이다. CLI는 평가자가 등록된 주체인지, 실행자와 다른 ID인지 검사하지만 실제 주체를 인증하거나 판정 내용의 진위를 증명하지 않는다. 변경 경로 검사는 선언을 검증하며 실행 sandbox를 제공하지 않는다. 원시 근거의 의미·실제 환경·권한은 호출자가 확인한다. fixture·비교 수치·선택만으로 성능 향상이나 인과 효과를 주장하지 않는다.

자체 동작 확인: `node --test <이 스킬 절대경로>/tests/*.test.mjs`. 이 검사는 설치 자산의 계약과 로컬 시나리오만 확인한다.
