# 실제 사용 회귀 시험

이 파일과 fixtures는 스킬 입력 지침이 아니라 검증용 자산이다. 작은 CLI 두 개의 코드를 별도 temp 작업영역에서 이식하고 원본을 보존한다. Rust 테스트에 원본 테스트 대응을 기록하고 fmt/build/test/Clippy를 실행한다.

호출자는 원본 언어, CLI 산출 형태, 출력 디렉터리, edition/환경·주석 언어·의존성 허용 범위를 지정한다. 연결 코드는 요청하지 않는다. 독립 실행 에이전트에는 skill과 원본·원본 테스트만 전달하고 비교 스크립트·기대 결과 설명은 답안으로 제공하지 않는다.

`verify_contract.py python <binary>`와 `javascript <binary>`는 원본과 candidate의 stdout/stderr 바이트 및 종료 코드를 고정·생성 입력에서 비교한다. 이 시험은 선택한 CLI 계약의 근거이며 모든 언어·실제 호스트 배포·성능 우위의 검증이 아니다.

추가 시나리오: 필수 도구를 사용할 수 없으면 INCOMPLETE/NOT_RUN과 부분 근거 반환, 원본·경로 누락 시 추측 없이 누락 반환, 변환 요청 없는 검토·설명은 변환하지 않기, import 연결이 필요하나 shim 미지정이면 임의 작성·완료 선언하지 않기. 시나리오별 실제 응답과 생성 파일을 기록한다.
